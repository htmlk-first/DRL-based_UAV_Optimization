# 1_TQL: Tabular Q-Learning 기반 UAV 경로 최적화

## 개요
Tabular Q-Learning(TQL)을 사용하여 2D 그리드 환경에서 UAV가 웨이포인트를 순서대로 방문하는 경로 최적화 문제를 해결합니다.  
에너지 제약과 장애물 회피를 동시에 고려합니다.

## 환경 설정
| 항목 | 설정값 |
|------|--------|
| 그리드 크기 | 10 × 10 |
| 행동 공간 | 이산 4방향 (상/하/좌/우) |
| 웨이포인트 | 2개 (중간 지점, 끝 지점), 순서대로 방문 |
| 장애물 | 고정 배치, 10개 |
| 에너지 예산 | 최단 경로 × 1.5배 |
| 시작 위치 | (0, 0) |

### 보상 체계
| 이벤트 | 보상 |
|--------|------|
| 이동 (매 스텝) | -0.5 |
| 웨이포인트 도달 | +50.0 |
| 전체 임무 완료 | +100.0 |
| 벽 충돌 | -5.0 |
| 장애물 충돌 | -10.0 |
| 에너지 소진 | -50.0 |

## 알고리즘
**Q-Learning** 업데이트 규칙:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

| 하이퍼파라미터 | 값 |
|----------------|-----|
| 학습률 (α) | 0.1 |
| 할인율 (γ) | 0.99 |
| 초기 ε | 1.0 |
| 최소 ε | 0.01 |
| ε 감쇠율 | 0.999 |
| 에피소드 수 | 5,000 |

## 실행 방법
```bash
cd 1_TQL
python train.py
```

- 최적 경로: 22 스텝, 잔여 에너지 5.0
